## Notes

- `TASK_NOTES` are append-only in the current implementation. Edit/delete/cancel controls, pagination, and load-more are not exposed; direct PATCH/DELETE attempts returned 404.
- Project Documents currently have no file upload/download/delete control or API route. Content is stored as versioned text.
- Report list has status filtering; no separate search control was present. The project Task Notes list search was exercised.
- The full code review and repository checks are summarized in [`workflow-report.md`](workflow-report.md); update its check section with the final command results before handoff.
