# Work (Task) FE Preview — Design

## Scope and product boundary

- Cross-project Member workspace: **`Workspace`** (`/workspace`) remains in the global Organization sidebar (`AppSidebar`).
- Project-scoped work entry: **`Workspace`** in the active Project sidebar section links to `/projects/{projectId}/work`. Project destinations (`Overview`, `Members`, `Workspace`, `Work Notes`, `Handover`, and `Settings`) use that sidebar; Project detail no longer repeats them in a horizontal header bar.
- Jira's "Space" concept is mapped to **Projects** inside the Workspace (`MemberWorkspace` + `WorkWorkspace`), where a Member selects an active Project they have access to (`GET /api/v1/iam/projects`) and works across all 10 Jira Space views (`Overview`, `List`, `Board`, `Calendar`, `Timeline`, `Development`, `Forms`, `Docs`, `Reports`, and `Work Notes`).
- Data source: frontend-only preview fixtures initialized into component state for task views and Work Notes. The current backend `origin/main` has D-03 Task persistence internals (`TaskDocument`, `TaskEventDocument`, repository and schema), while HTTP controllers are gated under D-05 contracts.
- Trust boundary: the page loads the signed-in user and organization context first, then loads the accessible Project(s) through the existing Project query hooks. Sample work items and work notes are labeled as preview data and never presented as saved backend records.

## Information hierarchy

1. **Project space header (`WorkPageHeader`)**: breadcrumb (`Projects / {Project name} / Work`), project monogram, project name and code, Project Workspace selector on `/workspace` (`Select project workspace`), explicit `Preview data` badge, `Share space` & `Fullscreen` toggles, primary `Create` button, and all 10 active workspace view tabs (`Overview`, `List`, `Board`, `Calendar`, `Timeline`, `Development`, `Forms`, `Docs`, `Reports`, `Work Notes`).
2. **Filter and view toolbar (`WorkToolbar`)**: search input (`key`, `title`, `assignee`, `reporter`), quick assignee pills, status scope pills, Priority/Assignee selects, Group By selector (`Status`, `Assignee`, `Priority`, `No grouping`), `✨ Ask AI` Copilot launcher, and `Export CSV`.
3. **Primary workspace canvas**:
   - **Overview view**: Jira Summary customization notice banner (`Take me to Reports` / `Dismiss`), four metric cards (`Total work items`, `Completed`, `In progress`, `Without due date`) plus status overview, recent work (ordered by `createdAt`), priority breakdown, work-type breakdown, team workload, and subtask progress panels.
   - **List view**: table with selection checkbox, expandable subtask hierarchy (`▶`/`▼`), interactive subtask checkboxes, inline status change dropdown, inline `+ Create inline work item` composer, and floating bulk action bar (`✓ Mark as Done`, `Move to In Progress`, `✕ Delete`, `Clear selection`).
   - **Board view**: four columns (`TO DO`, `IN PROGRESS` with `MAX 4` WIP badge, `IN REVIEW`, `DONE`) with HTML5 drag-and-drop & status transition selector, parent Epic badges, and inline `+ Create issue` per column.
   - **Calendar view**: monthly TailAdmin calendar grid with Monday-first weekday headers, previous/next/today controls, current-day ring, dated work item pills on their due dates, selected-day task list on narrow screens, and an `Unscheduled` section for items without a due date.
   - **Timeline view**: Gantt roadmap with expandable Epics & subtasks, timescale switcher (`Today` / `Weeks` / `Months` / `Quarters`), period navigation (`‹` / `›`), and inline bar schedule/color editor.
   - **Development view**: DevOps & SecOps hub with Key metrics (`Cycle time`, `Deployment frequency`, `Change failure rate`, `Open PRs`, `Vuln SLA`, `Build success rate`), 6 subtabs (`Connections`, `Pull requests`, `Repositories`, `Vulnerabilities`, `Deployments`, `Work suggestions`), interactive tool connection toggles, `+ Create fix task` from vulnerabilities into workspace backlog, and CLI context copy.
   - **Forms view**: Intake forms landing with templates (`Epic Intake`, `Bug Report`, `Feature Story`, `Operations Task`), active forms manager table, interactive 2-column Form Builder canvas with toggleable custom fields, and live Preview & Submit that appends a real `WorkItem` to the workspace.
   - **Docs view**: 3-mode documentation hub (`Document List` with SAG ingestion chunk badges & linked task pills, `Document Reader` with Confluence page tree, callout, architectural bullets, interactive checklist, & inline page editor, and `Confluence Gateway`).
   - **Reports view**: Analytics & velocity report center with `More reports` template directory (6 report types), 4 KPI summary cards, status/type/velocity breakdowns, SVG Sprint Burndown & Cycle Time charts, and paginated Work Items report table.
   - **Work Notes view**: embedded `WorkNotesWorkspace` scoped to the selected Project, providing the Member with activity updates, weekly report submission, and knowledge notes.
4. **Create Work Item dialog & AI Copilot modal**: `WorkCreateItemDialog` creates an in-memory preview item in the active view state; `WorkAiCopilotDialog` provides live Sprint & Task AI analysis over the active workspace state.
5. **2-Column Jira Work Item Detail modal (`WorkItemDetailDialog`)**: opens from List keys/titles, Board cards, Overview recent items, Timeline rows, Docs linked tasks, and Reports rows; features parent Epic breadcrumb, interactive subtask checklist + `+ Add a child work item`, live activity/comments composer, interactive Status/Assignee/Priority selectors, and Git branch creation.
